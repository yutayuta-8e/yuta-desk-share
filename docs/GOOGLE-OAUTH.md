# Google カレンダー接続の手順

yuta-desk のカレンダーは Google カレンダーを読み取り専用で表示する。接続には Google Cloud の OAuth クライアント（デスクトップ用）が要る。1 回だけ、15 分くらい。パスワードやトークンの値は AI に渡さない。

## 1. Google Cloud でプロジェクトを作る

1. https://console.cloud.google.com/ を開き、Google アカウントでログインする。
2. 上部のプロジェクト選択 →「新しいプロジェクト」→ 名前は `yuta-desk` → 作成。
3. 作ったプロジェクトを選択した状態にする。

## 2. Calendar API を有効にする

1. 左メニュー「API とサービス」→「ライブラリ」。
2. `Google Calendar API` を検索 → 開く →「有効にする」。

## 3. OAuth 同意画面を作る

1. 「API とサービス」→「OAuth 同意画面」。
2. User Type は「外部」→ 作成。
3. アプリ名 `yuta-desk`、ユーザーサポートメールとデベロッパー連絡先に自分のメール → 保存して次へ。
4. スコープは追加しなくてよい（アプリ側で `calendar.readonly` と `calendar.events` を要求する。後者はカレンダーのカードから予定を足す・直す・消すため、2026-10-28 から）→ 保存して次へ。
   - それより前に接続していた場合は、右クリックの「Google に再接続」で書き込みも許可し直す。
5. テストユーザーに自分の Google アカウントを追加 → 保存。
   - 公開状態は「テスト」のままでよい。テストのままだとトークンが 7 日で失効する。失効したらウィジェットの右クリック →「Google に再接続」。
   - 失効を避けたいときは「アプリを公開」を押す（Google の審査は不要。自分だけが使う）。

## 4. OAuth クライアント ID を作る

1. 「API とサービス」→「認証情報」→「認証情報を作成」→「OAuth クライアント ID」。
2. アプリケーションの種類は「デスクトップ アプリ」、名前 `yuta-desk` → 作成。
3. 「JSON をダウンロード」を押す。

## 5. JSON を置く

ダウンロードした JSON を次の名前と場所に置く。

```
%APPDATA%\yuta-desk\google-credentials.json
```

トレイアイコン →「設定フォルダを開く」でそのフォルダが開く。

## 6. 接続する

1. カレンダーウィジェットの「Google に接続」を押す（または右クリック →「Google カレンダーに接続」）。
2. ブラウザが開くので Google でログインし、「このアプリは Google で確認されていません」が出たら「詳細」→「yuta-desk（安全ではないページ）に移動」→ 許可。
3. 「接続しました」と出たらタブを閉じる。ウィジェットに予定が出る。

## 保存される場所

- `google-credentials.json`: クライアント ID とシークレット（自分で置いたもの）。
- `google-token.json`: アクセストークンとリフレッシュトークン。アプリが自動で更新する。
- どちらも `AppData\Roaming\yuta-desk` にあり、Vault（Google Drive 同期）には入らない。

## 外す

`google-token.json` を削除すれば未接続に戻る。Google 側で取り消すときは https://myaccount.google.com/permissions で yuta-desk を削除。
