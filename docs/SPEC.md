2026-10-24 のグリル（一問ずつの要件確認）で確定した内容。第1弾の実装はこの文書を正とする。

## 一言で

Windows 11 のデスクトップに常駐する、壁紙を活かした「光の線」のウィジェット群とデスクトップペット（2026-10-26 にリキッドグラスから刷新）。

目的（2026-10-26 本人が設定）: デスクトップをおしゃれに、可愛く、便利に！

## 閉じ条件（完成の定義）

次が全部満たされたら第1弾完成。報告は「確認済み／推測／未確認」を分ける。

1. 7 個（ランチャー・時計・カレンダー・タスク・バッテリー・usage・ペット）がデスクトップ層で同時に動く。
2. ドラッグ移動と位置記憶、右クリックメニュー、トレイメニュー、自動起動 ON/OFF が動く。
3. Google カレンダー接続は本人の OAuth 手順完了後に確認する。鍵が無い間は月表示だけで動く。
4. 24 時間放置してメモリ使用量が増え続けないことを確認する。

## ウィジェット

### A. ランチャー

- アプリ（exe）とフォルダのショートカットをグリッドで表示。
- グリッドは行×列を設定で変更可（3×3、1×5、2×4 など）。右クリックメニューからも選べる。
- ページ単位でスナップする横スクロール。下にページ位置の点。マウスホイールで横にページ送り。
- 登録は第1弾では設定ファイル（JSON）に手で書く。ドラッグ＆ドロップ登録は第2弾。
- アイコンは exe から自動抽出、フォルダは Windows 標準アイコン。起動は shell open で行う。
- アイコンの見た目は iOS 26 の「クリア」スタイル（参考: `docs/reference/ios-clear-icons-2026-10-24.png`）。抽出したアイコンを白い単色シルエットに変換し、半透明のガラスタイル（角丸、縁の光）に載せる。変換は輝度またはアルファからマスクを作る。設定で「フルカラー」に戻せる。
- 初期の登録内容は実装時に本人へ確認する（未決）。

### B. 時計

- 日付（曜日つき）と時刻。

### C. カレンダー

- 月表示。予定のある日に点を出し、日をタップでその日の予定一覧。
- データ元は Google カレンダー。アカウント内の全カレンダーを表示し、設定で非表示にできる。
- 読み取りだけ。予定の追加・変更はしない（第2弾以降。外部変更は本人承認事項）。
- 接続は Google Cloud の OAuth クライアント（デスクトップ用）。本人が作成して JSON を設定フォルダに置く。手順書は `docs/GOOGLE-OAUTH.md` に書く。トークンは Vault の外（アプリの設定フォルダ）に置く。

### D. 今日のタスク

- データ元は Vault の正本 `%USERPROFILE%/library/資料/ai-context/admin/タスク.md`。
- 書式: `- [ ] 期限 YYYY-MM-DD | 内容 | 補足`。「期限なし」節もある。
- 表示: 期限超過（赤）＋今日（強調）＋3 日以内。`返事待ち:` で始まる行は見た目を区別する。
- チェックで済にできる。裏で `yuta task done` を呼び、正本の書式を崩さない。誤タップ防止に「チェック→2 秒以内にもう一度で確定」の二段にする。
- 正本はファイル監視で再読み込みする（Grok Bot など他の書き手もいる）。

### E. バッテリー

- PC 本体の残量と、Bluetooth 機器の残量。
- ペアリング中の全機器を自動で拾い、残量が取れる機器だけ表示する。
- 取得は PowerShell 経由。本体は `Win32_Battery`、Bluetooth は PnP デバイスプロパティ `{104EA319-6EE2-4701-BD47-8DDBF425BBE5} 2`。
- 2026-10-24 の実機確認: 本体 96%、`myAir.0 OriMouse` 73%。

### G. AI usage（2026-10-24 追加）

- Claude Code、Codex、Grok Bot の利用量を表示する。1 週間枠と 5 時間枠（5 時間枠が無いサービスは 1 週間だけ）。
- 取得元は各サービスのローカル認証情報を使った読み取り API。本人のトークン値は表示もログもしない。
- 取れる見込み（実装時に検証、未確認）: Claude Code は OAuth の usage API、Codex は ChatGPT アカウントの usage API。Grok Bot（SuperGrok）は公開 API が見当たらないため、取れなければ「未対応」と表示する。
- 表示はサービスごとに残量のメーター（%）と、枠のリセット時刻。

### F. デスクトップペット

- 動物系オリジナル。見た目は仮（シンプルな図形）で、動きだけ先に作る。デザインは差し替えできる構造にする。
- 第1弾の振る舞い: 画面下を歩く・立ち止まる・寝る（ランダム）、マウスカーソルを目で追う、クリックで反応（跳ねる・吹き出し）。
- ウィジェットとの連動（タスク完了で喜ぶ、バッテリー低下で心配）は第2弾。
- 他のウィジェットと同じデスクトップ層に置く。最前面には出ない。

## デザイン v2「呼吸する光」（2026-10-26）

本人の指示「壁紙を活かしたデザインだけ固定して、すべて刷新」により、ブリーフ（`docs/design/brief-v2.md`）の 4 方向から A を選択。上のガラス表現（2026-10-24〜25 の各決定）はすべて置き換えた。

- 文字と数字は面ではなく「発光する線」。面・板・枠・影は出さない。
- 色は壁紙の最も鮮やかな色 1 つと白だけ。壁紙の平均輝度（main で計測、`luma`）が 150 を超えると、暗い線＋白いにじみに切り替える。
- 時計は自作の一筆書き数字（`digits.ts`）を SVG の線で描く。数字が変わると、その数字だけ 1.2 秒で一筆に書き直す。日付・文字は Zen Kurenaido。
- 呼吸は全ウィンドウ共通の 6 秒周期。時計の数字・日付・カレンダーの月と今日の輪だけが明滅する。10 fps のタイマーで CSS 変数 `--breath` を更新する（CSS アニメーションだと 60 fps で合成が走るため）。
- ホバーで光が集まる（`--gather`）。タスクは光の点、1 回押すと輪になり、2 回目で済。ランチャーのアイコンは淡いシルエット＋光の縁（アイコンの台座は取り除く）。ペットは 1 本の光の線で描いた生き物。
- 実装は `src/renderer/src/light/`（`Light.tsx`、`light.css`、`testBg.tsx`）。three.js はウィジェットから外した。
- 時計の数字だけ光学的なカーニングをかける（`light/kerning.ts`）。数字の左右の輪郭を帯ごとに測り、一番近い距離と平均距離の混ぜ合わせで、どの組み合わせも「00」と同じ見た目の間隔にそろえる。コロンは時計の中央に固定し（本人の指示）、時はコロンから左へ、分は右へ詰めて並べる。枠の幅は 00〜23 時と 00〜59 分で一番広い組み合わせに合わせて固定する。時刻が変わると、残る数字は 1.2 秒で新しい位置へすべる。手調整（本人の指示）: 丸同士（00、08、09 など）をさらに 8 単位詰める。分とコロンの間は数字同士の 0.7 倍、時とコロンの間は 0.85 倍。確認用に `YD_KERN=丸の詰め,時側,分側` で上書きできる。
- 数字の 9 は、ほかの数字より 5% 大きい（本人の指示、2026-10-27）。箱の中央を基準に形だけ広げ、線の太さはほかと同じ。時計のほか、ランチャーの数字のマークにも効く。
- 9 は 5% 広げたあと 2.45 上げてある（本人の指示「少し下目にいる」、同日）。広げた時点では下端が 116.45、中心の高さが 68.1 で、ほかの数字（中心 63.9〜66.4、0・1・2・4・8 の下端は 114）より下に寄っていた。いまは下端 114、中心 65.7 で、0・1・2・4・8 と同じ線に乗る。
- 0 は楕円（94x98）、8 は上下 2 つの楕円で、6 と 9 の輪と同じ曲線にそろえた（2026-10-26 本人の指示）。
- 実測（2026-10-26 朝、実機）: CPU 約 2%（12 コア合計比）、メモリ約 1.1 GB（3D 版は約 2 GB）。

## 第2弾の範囲（2026-10-26 本人回答）

目的「デスクトップをおしゃれに、可愛く、便利に！」に向けて、候補から本人が選んだもの。閉じ条件は、実装して実機で動作・CPU 5% 未満・メモリ横ばいを確かめ、項目ごとにスクショか動画で見せること。本人の操作が要るものは手順を渡した時点で完了。

- やる: 壁紙が変わったら光の色をなめらかに切り替える／時間帯の表現（朝っぽい・夜っぽい）／毎正時の合図（時計が光り、ペットが知らせる）／タスクを済にしたときの光の粒／予定の 10 分前にペットが知らせる／ランチャーへのドラッグ登録と並べ替え／旧 3D コードの片付け（済）。
- ペット: 本人は「今は 1 割」。方向性を本人と決めて作り込む。
- 本人待ち: 吹き出しの言葉、Google カレンダーのログイン、再起動での自動起動確認。
- やらない: 自作フォント（文字は Zen Kurenaido のまま、時計の数字は自作のまま）、顔をよける自動配置、ウィジェットからのタスク追加。

## 第2弾の実装（2026-10-26）

グリル（2026-10-26）で決めたこと: ペットはいたずらっ子でマイペース、画面のどこでも動く（ただしウィジェットの上は通れないので、よけて飛ぶ。デスクトップ内の窓どうしは透過で重ならないため）。毎正時は光が数字を一周走り、ペットが「15時だよ」と言う（6〜23時）。0時に「おやすみ」、0〜6時は静か。6時以降に初めてマウスを動かすと「おはよう」。タスクを済にすると光の粒がはじけ、ペットが喜ぶ。予定のお知らせは作らない。ペットの見た目は他が完成してから決める。時間帯の表現は色を変えず、光の強さ・夜の星・ペットの過ごし方で出す。

本人の追加要望（同日）:
- ランチャーのフォルダは Files で開く（`launcher.openFoldersWith` を `explorer` にすると従来どおり）。
- ランチャーの各アイコンを、右クリックから光のマーク（絵 18 種か数字 1〜9）に変えられる。Filmora のアイコンはショートカットの参照先から取るよう修正。
- バッテリーと使用状況の数字はカーニングし、右そろえの列にした。`usage.hidden` に入れたサービスは出さない（本人設定で Codex を非表示）。
- Grok Bot の使用状況: 公開 API がなく、Grok Bot アプリは手元に使用量を保存していない（サインイン状態などだけ）。取るにはログイン情報を扱う必要があるため対応しない。
- カレンダーの月を大きく。「今日」ボタンは「今日に戻る」にし、別の月や日を見ているときだけ出す。
- ウィジェットの移動は編集モードのときだけ。長押し（0.55 秒）で全ウィジェットが編集モードになり、クリックか 15 秒操作なしで終わる。右クリックとトレイからも切り替えられる。
