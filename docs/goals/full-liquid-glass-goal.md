# ゴール: yuta-desk 全体をリキッドグラスで作り直す

作成: 2026-10-25 23:30。無人で進める。本人の要望は 2026-10-24〜25 のセッションから全部拾った（下記）。

## これまでの要望（全部守る）

デザイン方向
- 壁紙が主役。ウィジェットは「そこに薄いガラスがある」程度の気配。
- カードは全廃。文字・数字・アイコンだけが壁紙の上に浮く。
- 見出し・件数・年・案内文は出さない。矢印や「Google に接続」はホバー時だけ。
- 色は壁紙から拾う（チップ・バー・今日・ページ点）。
- 書体: 時計の数字は自作の丸い形、文字は M PLUS Rounded 1c。
- 時計は画面中央上、中央ぞろえ。時計と日付の間隔は広め（24px）。
- 動き: ホバーで縁の光が増す。数字の切り替わりはクロスフェード。光はマウスに追従。ホバーが外れたら必ず元に戻る。

ガラスの質感（時計で到達したもの、全部に適用）
- 本物の 3D（three.js）。物理ベース材質: 透過 1、IOR 1.6、分散 0.3、クリアコート。
- 中は壁紙そのまま（色・明るさを変えない）。縁で背景が曲がる。フレネルの細い光ライン 1 本。
- 断面は完全な円（ぷにっとしたビーズ）。角は全部カーブ、頂点を持たない。
- アウトラインの硬い線は無し。霜も無し。
- 壁紙は画素ぴったりに背景に貼り、環境マップにも使う。四角い板の境界を見せない。
- 光源: 左上キー＋フィル＋マウス追従の点光源。白い点が散らばらない。ブルームは弱め。

個別
- 時計: 自作数字（横長 130x130 の箱、線 46、完全な円断面）、日付はフォント輪郭を押し出したガラス。
- バッテリー・usage: 大きい数字（46px 相当）＋名前＋バー。数字は時計と同じ自作数字、名前と「%」はフォント押し出し。
- タスク: 1 行 1 件、行カードなし、細い区切り線。超過＋今日＋3 日以内。「返事待ち」は区切り線の下。チェック 2 段で `yuta task done`。タッチパッドでスクロール。
- カレンダー: 月の表＋選んだ日の予定、日曜始まり、曜日に色なし、横スクロールで 1 か月ずつ。
- ランチャー: アイコンだけ（名前はホバー）、タイルなし、間隔を詰める、3x3 で横スクロールのページ送り、グリッド可変、クリアアイコン。
- ペット: 動物系の仮デザイン、ガラスの体、歩く・寝る・目で追う・クリック反応、吹き出しの言葉は `config.json`。
- 入力: 受け皿ウィンドウ方式（タッチパッドのスクロールが届く）。1px 枠なし。
- 自動起動: Startup フォルダの VBS ランチャー（変更しない）。

## 進め方

1. 共通部品 `GlassScene`: 1 つのウィジェット = 1 つの three.js シーン。中に複数の「ガラス要素」（数字列・文字列・バー・点・アイコン）を置ける。壁紙背景・環境マップ・光・ブルーム・必要時描画・ホバー・マウス光を一括で持つ。
2. 時計 → バッテリー → usage → タスク → カレンダー → ランチャー → ペットの順に移行。各ウィジェットは移行後に撮影して比較。
3. 悪化したら戻す。同じ方針で 3 回失敗したら凍結して別案。
4. 1 時間ごとに `docs/goals/full-liquid-glass-journal.md` に 3 行追記。
5. 最後の 30 分は機能追加禁止: 負荷・全画面撮影・docs・コミット・Vault。
